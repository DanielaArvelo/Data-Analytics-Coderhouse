# 📊 Análisis de Ventas – Asistencia al Viajero

## 📝 Descripción

Este proyecto consiste en el análisis de ventas de una empresa ficticia de asistencia al viajero, con el objetivo de identificar tendencias de consumo, perfiles de clientes y oportunidades comerciales entre 2014 y 2020.
Se diseñó un tablero interactivo en Power BI para visualizar resultados clave y facilitar la toma de decisiones.

## ⭐ Características

- Análisis exploratorio de datos (ETL con Power Query).
- Modelado de datos con esquema estrella y relaciones entre tablas.
- Creación de medidas DAX (Total Ventas, Ingresos Totales, Ticket Promedio, variaciones YoY, etc.).
- Segmentación por canales de venta, tipo de producto, anticipación de compra y tipo de cliente.
- Tablero dinámico con múltiples páginas:

  - Visión General de Ventas
  - Análisis de Canales y Productos
  - Perfil del Cliente

## 🛠️ Tecnologías utilizadas

- Excel: Limpieza inicial y exploración de datos.
- Power BI (Power Query + DAX): Modelado de datos, creación de medidas y visualizaciones.
- draw.io: Diseño de diagrama entidad-relación.
- Canva: Diseño de presentación final.

## 📂 Estructura del repositorio

- dataset → Contiene las tablas en formato CSV/Excel (anonimizadas para uso educativo).
- dashboard.pbix → Archivo de Power BI con el tablero interactivo.
- Informe_Final.pdf → Documento completo del análisis, hallazgos y conclusiones.

## 🚀 Cómo usar el proyecto

- Clonar el repositorio:
git clone https://github.com/tu_usuario/asistencia-al-viajero-analytics.git
- Abrir el archivo dashboard.pbix en Power BI Desktop para explorar el tablero.

## 📈 Principales hallazgos

- Fuerte estacionalidad en ventas (picos en verano e invierno).
- Planes simples representan >90% de las ventas, pero los de larga estadía generan mayor ticket promedio.
- Europa y América del Norte concentran la mayor facturación.
- Oportunidad de reforzar el canal online, que muestra caídas recientes.
- Los grupos y familias generan ingresos más altos por operación.
